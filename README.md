# Kompendium informatyczne

Prosta strona z notatkami dla uczniów technikum informatycznego.

## Przedmioty

- Bazy danych
- Witryny i aplikacje internetowe
- Urządzenia techniki komputerowej
- Sieci komputerowe

## Uruchomienie lokalnie

Najprościej otworzyć `index.html` w przeglądarce.

Można też użyć rozszerzenia **Live Server** w Visual Studio Code.

## Struktura

```text
kompendium-informatyczne/
├── index.html
├── styles.css
├── script.js
├── README.md
└── .gitignore
```

## Plan rozbudowy

Docelowo każdy przedmiot otrzyma osobny katalog i własny spis treści.
